# spdrdr

RSVP speed reading library and web app.

## Build

Install dependencies:

```bash
bun install
```

Build the library:

```bash
bun run build
```

Build the web app:

```bash
bun run build:app
```

## Development

Run tests:

```bash
bun test
bun test --watch
```

Type checking:

```bash
bun run typecheck
```

Lint and format:

```bash
bun run lint
bun run format
```
